# Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reshape Iron Log into five purpose tabs (Today · Plan · Progress · Friends · Me) with the "Bold Block" look (accent-tinted gradient, light/dark), levelling badge families, a challenge podium and a queued celebration card, without touching stored data, rules or publishers.

**Architecture:** `state.view` stays a screen id; a pure `nav.js` registry maps screens to tabs and section pills. One shared tab bar + pill switcher is drawn by `render()`. Badge families (`badge-art.js`) and celebration cards (`celebrate.js`) are pure modules derived from the existing 24 badges. All screens keep their `render*()` functions; `find` is the only new view, Today keeps id `log`, Me keeps id `profile`.

**Tech Stack:** plain JS/CSS in `public/index.html`, ES modules, Node test runner (`npm test`), screenshot harness (Edge headless).

**Spec:** `docs/superpowers/specs/2026-10-19-redesign-design.md`

## Global Constraints
- No change to Firestore documents, `firestore.rules`, publishers (`maybePublish`, `publishProgress`), `settingsDoc`, `wipePlan`, privacy/terms pages. `seenBadges` logic and XP rules unchanged.
- Never hardcode blue: use `var(--accent)`, `--accent-ink`, `--accent-soft`; `--good`/`--danger` never follow the accent; reward colours (gold `#ffd84a`/`#ffb020`, mint `#7be0c3`, coral `#ff9c8a`, silver `#aab2c5`, bronze `#d9783c`) are fixed tokens with near-black ink.
- Logical CSS properties only (RTL); max-width 640px; no horizontal page scroll at 320 px; `prefers-reduced-motion` disables new animation; keyboard focus visible; buttons have accessible names.
- Every new visible string needs an `AR.ui` entry (family names in `AR.names.family`); no glued strings; dynamic strings use `t()/tn()`.
- Every new `public/*.js` goes in `APP_SHELL` in `sw.js`; `VERSION` becomes `iron-log-v26`.
- Never use `\`` inside Write content for backticks; edit `index.html` with the Edit tool, one region at a time; after any edit that moves markup run the harness.
- Do not deploy without the owner's explicit approval.

## Review Focus
- A saved `ironlog.view` of `more`, `journey`, `delete`, `coach`, garbage or `null` must never leave a blank screen (Task 1, Task 4).
- First server sync on a new device must show no celebration storm and must not overwrite `seenBadges` (Task 9).
- Dot/count for friend requests plus challenge invites must show on the Friends tab and Challenges/Friends pills, and clear when handled (Task 4).
- Custom very-light and very-dark accents must keep text readable on cards, buttons and the gradient (Task 3, Task 11).
- Arabic/RTL: tab order, pills, podium (2-1-3 stays), ring and bars stay LTR; numbers isolated (Task 10, Task 11).
