# Injuries / Exercises to Avoid Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A person marks body areas that hurt and single exercises to avoid; every place that suggests an exercise leaves those out, and anything already on their days or in their history is marked with a warning instead of changed.

**Architecture:** A new standalone pure module `public/injuries.js` holds the seven areas, the explicit joint table for all 183 library exercises, and the helpers (`avoidFilter`, `avoidedBecause`, `cleanAvoid`, `hiddenAvoidCount`, `jointsOf`). `settings.avoid` stores the choice. The filter is applied next to the existing gym filter (suggestions, type-ahead, Coach, the journey's `buildPlan`); a new "Injuries" card on My Gym sets it; warnings mark existing items.

**Tech Stack:** plain ES modules, no build; Node test runner (`npm test`), Playwright harness (`tests-ui`).

**Spec:** `docs/superpowers/specs/2026-10-24-injuries-design.md`

## Global Constraints
- Windows, files are CRLF in git (autocrlf). Edit with the Edit/Write tools or a small Node patch script written with the Write tool. **Never put a regex, `\b` or `\n` inside a shell heredoc** (backslashes get eaten or turned into control characters). Check with `grep -lP '\x08'` over `public tests tests-ui` after patching.
- Every visible string needs an Arabic entry in `public/lang-ar.js` (`npm test` lists what is missing); area names live in `AR.names.area` (a missing one fails a test, like equipment names). No glued strings: `t("... {n}", {n})`. Digits 0-9, Latin units. Targets 44px, text 12px minimum.
- `public/injuries.js` imports nothing (no cycle with `exercise-library.js` or `plan-tools.js`, which import it).
- Areas, in this order: `shoulder, elbow, wrist, lower-back, hip, knee, ankle`.
- `settings.avoid = {areas?, exercises?}` omitted when both empty; names 1-80 characters, at most 100 exercises; matching is case-insensitive. Defaults change nothing: no `avoid` means every function returns its input unchanged.
- Never hide or remove what the person already has (days, today's workout, history, Lifts, templates they apply); only suggestions, type-ahead library names, Coach suggestions and the generated week are filtered.
- Round-trip rule: the settings snapshot parser, `store.saveSettings`, `settingsDoc`, `cleanSettings` must all carry `avoid`.
- Ruling (spec said a pending-draft overlay): `avoid` is saved immediately on each tap and no overlay is used; Firestore's local-first snapshot carries the write, as already proven by `setBodyweight`.
- Bump `VERSION` in `public/sw.js` (check the file; v45 is live at the time of writing, so `iron-log-v46`) and add `/injuries.js` to `APP_SHELL`. Commit messages end with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

## Review Focus
- Case: "pull-up" vs "Pull-up" in `avoid.exercises`; library names resolved through `resolveAlias` where the library does it.
- A person who avoids a custom (non-library) exercise: it has no joints, only the by-name rule applies.
- Prototype-like names (`constructor`) in `JOINTS` lookups and in `avoid.exercises`.
- `buildPlan` with an area chosen so that a whole muscle has nothing left (for example every Calves exercise loads the ankle): no crash, a note, a day left out cleanly; the exhaustive goal x days x experience x gym test still passes with and without `avoid`.
- "Show all" really shows everything (gym and injuries) and the avoided exercises keep their warning when shown.
- "Skip it" never removes an exercise that has sets.
- The joint table is reviewed by the owner (Task 2 produces the review list); tests must not make later corrections painful (assert structure and sanity examples, not every cell).

### Task 1: The injuries module

**Files:**
- Create: `public/injuries.js`, `tests/injuries.test.js`
- Modify: `public/sw.js` (APP_SHELL only)

**Interfaces:**
- Produces: `AREAS` (the seven ids, in order); `JOINTS = {}` (filled in Task 2; empty here); `jointsOf(name, joints = JOINTS) -> string[]` (case-insensitive, own-key lookup, `[]` for unknown/custom names, never throws); `avoidFilter(names, avoid, joints = JOINTS) -> names` (removes a name that is in `avoid.exercises` (case-insensitive) or whose joints intersect `avoid.areas`; `avoid` missing/empty returns `names` itself); `avoidedBecause(name, avoid, joints = JOINTS) -> {exercise: boolean, areas: string[]}` (areas in `AREAS` order; both empty = not avoided); `cleanAvoid(obj) -> {areas?, exercises?}` (areas: known ids, de-duplicated, in `AREAS` order; exercises: strings 1-80 characters trimmed, de-duplicated case-insensitively keeping the first spelling, at most 100; a key is omitted when empty; non-objects give `{}`); `hiddenAvoidCount(lists, avoid, joints = JOINTS) -> number` (sum over lists of removed names).
- The optional `joints` argument lets Task 1 test with a small table.

- [ ] **Step 1: Write the failing tests** (`tests/injuries.test.js`) with `const J = {"Squat":["knee","hip","lower-back","ankle"], "Bench Press":["shoulder","elbow","wrist"], "Crunch":[], "Lateral Raise":["shoulder"]}`:
  - `AREAS` equals the seven ids in order.
  - `jointsOf("Squat", J)`, `jointsOf("squat", J)` equal the entry; `jointsOf("Zottman", J)`, `jointsOf("constructor", J)`, `jointsOf(undefined, J)`, `jointsOf("Crunch", J)` are `[]`; the result is a copy (mutating it does not change `J`).
  - `avoidFilter(["Squat","Bench Press","Crunch","Zottman"], {areas:["knee"]}, J)` keeps all but Squat; `{exercises:["bench press"]}` removes Bench Press only; both together remove both; `{areas:[], exercises:[]}`, `{}`, `null`, `undefined` return the same array object; an unknown area id removes nothing; a custom name in `exercises` is removed; input array is not changed.
  - `avoidedBecause("Squat", {areas:["ankle","knee"], exercises:["squat"]}, J)` is `{exercise:true, areas:["knee","ankle"]}` (areas in `AREAS` order); `("Crunch", {areas:["knee"]}, J)` is `{exercise:false, areas:[]}`.
  - `cleanAvoid`: `{areas:["knee","knee","moon","shoulder"], exercises:[" Squat ","squat","", 5, "x".repeat(81)]}` -> `{areas:["shoulder","knee"], exercises:["Squat"]}`; 101 distinct names are cut to 100; `{areas:[], exercises:[]}`, `null`, `[]`, `"x"` -> `{}`; `{areas:"knee"}` -> `{}`.
  - `hiddenAvoidCount([["Squat","Crunch"],["Bench Press","Squat"]], {areas:["knee"]}, J)` is 2; `({}...)` 0.

- [ ] **Step 4: Add `/injuries.js` to `APP_SHELL` in `public/sw.js`.**
