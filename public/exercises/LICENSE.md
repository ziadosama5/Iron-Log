# Exercise drawings

The SVG drawings in this folder are adapted from **Everkinetic** (https://github.com/everkinetic/data).
They were recolored (to follow the app's light/dark theme) and minified by `tools/import-exercises.mjs`.

Original work licensed under **Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)**:
https://creativecommons.org/licenses/by-sa/4.0/

These adapted files are shared under the same license.

## Hand-drawn figures

The 14 drawings for Face Pull, Hip Thrust, Plank, Pec Deck, Reverse Pec Deck, Arnold Press, Machine Shoulder Press,
Chest Dip, Overhead Cable Extension, Stiff-leg Deadlift, Bulgarian Split Squat, One-arm Dumbbell Row, Hanging Leg Raise
and Russian Twist were drawn for Iron Log from code (tools/draw-exercises.mjs). They are original work and are shared
under the same CC BY-SA 4.0 license as the rest of this folder.
